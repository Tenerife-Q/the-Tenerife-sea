### 第一部分：代数视角的 Nim 游戏严格证明

要证明“异或和（XOR）决定胜负”，在组合博弈论中，我们需要满足由 Sprague 和 Grundy 提出的**三个代数判定定理**：
1. **终点必败**：终点状态的算式结果必须为 0。
2. **零必转非零 ($0 \to \neq 0$)**：任何结果为 0 的状态，经过**任意一次**合法操作后，算式结果必然变成非 0。
3. **非零必能转零 ($\neq 0 \to 0$)**：任何结果非 0 的状态，**必然存在至少一种**合法操作，使得算式结果变成 0。

只要满足这三条，我们就能从代数上断定：**结果为0是必败态，非0是必胜态。**

现在，我们引入代数定义：
设 $n$ 个变量 $x_1, x_2, \dots, x_n$。
定义状态函数 $S = x_1 \oplus x_2 \oplus \dots \oplus x_n$。
*异或的核心代数性质：① 交换律与结合律；② 自己异或自己等于0，即 $A \oplus A = 0$；③ 若 $A \oplus B = C$，则 $A = B \oplus C$。*

#### 证明过程：

**定理 1（终点必败）**：
终点是所有 $x_i = 0$。代入函数：$S = 0 \oplus 0 \dots \oplus 0 = 0$。成立。

**定理 2（零必转非零）：**
假设当前 $S = 0$。我们进行任意一次合法操作，将某个 $x_i$ 变为 $x_i'$（题目要求必须拿走石头，所以必须满足 **$x_i' < x_i$**）。
操作后的新状态函数 $S'$ 是多少？
利用异或性质：我们将旧的 $S$ 抠掉 $x_i$，换成 $x_i'$。
$S' = S \oplus x_i \oplus x_i'$
因为前提是 $S = 0$，代入得：
$S' = 0 \oplus x_i \oplus x_i' = x_i \oplus x_i'$
因为 $x_i' < x_i$，即 $x_i' \neq x_i$，所以两个不相等的数异或，结果**绝不可能为 0**。
推导完毕：无论你怎么操作，新的 $S'$ 必不为 0。成立。

**定理 3（非零必能转零）：**【极其优美的数学构造】
假设当前 $S \neq 0$。
因为 $S \neq 0$，它的二进制表示中必然有最高位的 `1`（假设在第 $k$ 位）。
根据异或的定义，在所有的 $x_1, x_2 \dots x_n$ 中，**必定存在至少一个 $x_i$**，它的第 $k$ 位也是 `1`（否则不可能异或出第 $k$ 位的 `1`）。
我们选中这个 $x_i$，目标是构造一个 $x_i'$，使得操作后的 $S' = 0$。
令 $S' = S \oplus x_i \oplus x_i' = 0$
利用异或性质解这个方程：等式两边同时异或 $(S \oplus x_i)$：
**$x_i' = S \oplus x_i$**
现在，唯一需要证明的就是：这个操作合法吗？即 **$x_i' < x_i$ 是否成立？**
看二进制：$x_i$ 的第 $k$ 位是 `1`，$S$ 的第 $k$ 位也是 `1`。
当它们异或（$x_i \oplus S$）时，第 $k$ 位变成了 `0`！而高于 $k$ 的位，因为 $S$ 在那些位都是 `0`，所以 $x_i$ 在那些位的值完全没变。
一个数的高位不变，某一个有效的最高位从 `1` 变成了 `0`，这个数**必定严格变小了**！
证明完毕：我们不仅证明了存在这种操作，还求出了代数解析解 $x_i' = S \oplus x_i$。成立。

**总结**：正是因为**“按位异或运算”完美符合这三个代数递推条件**，它成为了组合博弈论中唯一指定的状态方程。

### 第二部分：遇到文字/抽象问题，怎么往这上面靠？

数学建模能力，就是**剥离表象，提取代数结构**的能力。以后遇到奇奇怪怪的博弈题，请严格执行以下 **“抽象四步法”**：

#### Step 1：判定适用范围（它配不配用 Nim 理论？）
只有满足以下四个条件的“公平组合游戏（ICG）”，才能用这套理论：
1. **两人交替操作**。
2. **有限步内必结束**（没有死循环，没有概率）。
3. **信息完全公开**（没有隐藏牌，没有掷骰子）。
4. **公平原则**（面对同一个状态，先手和后手能做的操作完全一样。像象棋这种“你只能动红子，我只能动黑子”的**不适用**）。

#### Step 2：寻找“独立子空间”（切分变量）
Nim 游戏的核心是“$n$ 堆石子是**互相独立**的，操作一堆不影响另一堆”。
在文字题里，你要寻找什么是“独立的”。
*   *例题*：一个棋盘上有 5 枚硬币，每次只能把一枚硬币往左移，不能越过其他硬币。
*   *抽象*：虽然在同一个棋盘上，但每一枚硬币到其左边障碍物的距离，就是它的“独立石子数”。5 枚硬币等价于 5 个独立变量 $x_1 \dots x_5$。

#### Step 3：剔除“可抵消代数项”（降维）
这就是你在上一道 Staircase 题中见识过的。
当你写出状态转移方程时，发现有些操作会引发变量的互相传递（比如 $A \to A-x, B \to B+x$）。
你需要进行代数推演：如果一方执行了增加变量的操作，另一方是否可以立刻执行一个反向操作将其抵消？
*   如果**能抵消**：这个被增加的变量就是“冗余维度”。在代数模型中直接将这个维度**置 0 或划掉**。
*   将剩下的维度视作核心变量。

#### Step 4：求单一维度的等效值（求 SG 函数）
把变量剔除干净后，剩下的每个独立变量 $x_i$，它的操作规则可能依然不是标准的“随便减”（比如只能减素数，只能减平方数）。
这时候，你需要对其进行**线性映射（计算 SG 函数）**。
定义一维状态转移的 `mex` 函数：
$SG(x) = \text{mex}(\{SG(x_1'), SG(x_2') \dots SG(x_k')\})$
其中 $x_j'$ 是 $x$ 经过合法操作能变成的下一个状态。
*代数意义*：$SG(x)$ 的结果，就是这个受到奇葩规则限制的数字 $x$，在标准 Nim 游戏中**代数等效的真实数值**。
*(对于大规模数据，往往在纸上算前几个 $SG(x)$，就能找到诸如 $x \pmod 4$ 的代数周期规律)*。

#### Step 5：写出终极代数方程
经过前面的抽象，你得到了 $n$ 个独立且等效的变量：
$Y_1 = SG(x_1)$
$Y_2 = SG(x_2)$
$\dots$
$Y_n = SG(x_n)$
列出终极方程：
**$S = Y_1 \oplus Y_2 \oplus \dots \oplus Y_n$**
如果 $S \neq 0$，输出 `First win`；如果 $S = 0$，输出 `Second win`。

### 举一反三的练习示范

**抽象问题**：有 $N$ 个盒子，每个盒子里有一些球。每次可以从一个盒子里拿走任意多的球，如果这是该盒子里的最后几个球，你还可以选择是否把这个空盒子彻底摧毁。最后没球也没盒子拿的人输。

**代数转化思维**：
1. **判定**：双人、确定、有限、平等，属于 ICG 游戏。
2. **子空间**：每个盒子是独立的，总共 $N$ 个独立变量。
3. **降维**：摧毁空盒子有意义吗？空盒子无法再操作，摧毁它是增加了一次额外行动机会。它是一个具有特定状态的值。
4. **求 SG（等效值）**：
   * 空盒子：能被摧毁（变成什么都没了，状态全无也就是0）。所以 $SG(\text{空盒子}) = \text{mex}(\{SG(0)\}) = \text{mex}(\{0\}) = 1$。
   * 有 $x$ 个球的盒子：拿完球后，可以选择留着空盒子（状态变为空盒子），或者摧毁空盒子（状态变成啥也没有0）。
   经过数学推导，有 $x$ 个球的盒子的代数等效值其实等于 $x+1$（或者类似规律，取决于具体计算）。
5. **合体**：将所有盒子的代数等效值异或起来，判定是否为 0。

看到了吗？不去脑补具体的游戏画面，**只看变量的增减方程，剔除冗余项，映射 SG 等效值，最后异或求和**。这就那些在 ACM 竞赛里 10 分钟秒杀博弈题的高手大脑里的真正回路。
