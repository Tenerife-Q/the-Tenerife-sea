### 一、 约数之和（Sum of Divisors）的数学原理

我们要算一个数所有约数加起来的总和。
假设这个数字是 $N = 12$。它的质因数分解是 $12 = 2^2 \times 3^1$。
$12$ 的约数有：$1, 2, 4, 3, 6, 12$。加起来是 $28$。

**1. 乘法分配律的魔法**
数学家发现，不需要把所有约数一个个找出来相加，利用**乘法分配律**可以直接搞定。
我们把 $2$ 的所有幂次写在一个括号里，把 $3$ 的所有幂次写在另一个括号里相乘：
$$(2^0 + 2^1 + 2^2) \times (3^0 + 3^1)$$
展开这个式子，你会发现它完美对应了所有约数：
$$= (1 + 2 + 4) \times (1 + 3)$$
$$= 1\times1 + 1\times3 + 2\times1 + 2\times3 + 4\times1 + 4\times3$$
$$= 1 + 3 + 2 + 6 + 4 + 12$$
左边算出来是 $7 \times 4 = 28$，完美吻合！

**2. 转化为等比数列求和**
所以，对于任意数字 $N = p_1^{k_1} \times p_2^{k_2} \dots$，约数之和就是：
$$(1 + p_1 + p_1^2 + \dots + p_1^{k_1}) \times (1 + p_2 + \dots + p_2^{k_2}) \dots$$

括号里的一长串，就是高中的**等比数列求和**。
公式为：$1 + p + p^2 + \dots + p^k = \frac{p^{k+1} - 1}{p - 1}$

**3. 代码怎么写？（逆元的出场）**
题目要求结果对 $10^9+7$ 取模。模运算里**不能直接用除法**，除以 $(p-1)$ 必须变成**乘以 $(p-1)$ 的逆元**。
逆元怎么求？费马小定理告诉我们，求 $X$ 的逆元，就是算 $X^{10^9+5} \pmod{10^9+7}$。

代码极其简单（精简变量名后）：
```cpp
// 算分子: (p^(k+1) - 1) % MOD
ll fenzi = (qpow(p, k + 1, MOD) - 1 + MOD) % MOD;
// 算分母的逆元: (p - 1)^(MOD - 2) % MOD
ll fenmu = qpow(p - 1, MOD - 2, MOD); 
// 乘进总和里
ans_sum = ans_sum * (fenzi * fenmu % MOD) % MOD;
```

### 二、 约数之积（Product of Divisors）的两座大山

约数之积的难点在于：**全局公式是 $N^{d/2}$（$d$ 是约数总个数）。要在指数上除以 2，但在 $\pmod{10^9+6}$ 的世界里，2 没有逆元，除法失效！**

为了绕开这个“无法除以 2”的死锁，有两种极其聪明的方法。

#### 方法一：递推法（像滚雪球一样积累）

**核心思想：既然最后一起算会卡在除以 2，那我就每拿到一个质因数，就把当前的乘积更新一次。**

假设我们刚才已经处理完了一些质数，算出的旧乘积叫 `old_prod`，旧的约数个数叫 `old_cnt`。
现在我们引入了一个新的质数 $p$，它的幂次是 $k$。新的乘积 `new_prod` 由两部分构成：

1.  **旧乘积被放大了：**
    原来算好的 `old_prod`，现在要分别跟新质数的 $p^0, p^1, p^2 \dots p^k$ 结合。
    这意味着 `old_prod` 连乘了 $k+1$ 次。
    **产生的部分 1：`qpow(old_prod, k + 1, MOD)`**
2.  **新质数 $p$ 自己产生的贡献：**
    新质数引入了 $p^1 \times p^2 \times p^3 \dots \times p^k$。
    底数相同，指数相加：$1 + 2 + \dots + k = \frac{k(k+1)}{2}$。
    注意！这个 $\frac{k(k+1)}{2}$ 是普通的数学计算，**相邻两数相乘必为偶数，绝对能被 2 整除！** 我们在这里除以 2 是安全的。
    并且，这个新贡献会对旧的每一种组合（共 `old_cnt` 种）都发生一次。
    **产生的部分 2 的指数：`power_p = (k * (k + 1) / 2) % MOD_EXP * old_cnt % MOD_EXP`**
    **产生的部分 2：`qpow(p, power_p, MOD)`**

把这两部分乘起来，就是新的乘积！完美避开了在取模后除以 2 的窘境。

#### 方法二：分类讨论法（直接给公式动手术）

**核心思想：我非要用 $N^{d/2}$ 这个公式！既然模运算下不能除以 2，那我在取模之前、在普通的整数世界里，把这个 2 给约掉不就行了？**

因为 $d = (k_1+1) \times (k_2+1) \times \dots$，我们分两种情况看这个 $d$：

*   **情况 A：不是完全平方数**
    这意味着，这些 $(k+1)$ 里面，**肯定至少有一个是偶数**。
    那太好了！在用 `for` 循环把它们乘起来算 $d$ 的时候，一旦碰到**第一个**偶数，我当场把它除以 2。
    这样算出来的最终结果 `exp_cnt`，实际上就已经提前除过 2 了。
    直接算 $N^{\text{exp\_cnt}} \pmod{10^9+7}$ 即可。
*   **情况 B：是完全平方数**
    这意味着所有的 $k$ 都是偶数，导致所有的 $(k+1)$ 都是奇数。奇数乘奇数还是奇数，$d$ 是奇数，没法除以 2。
    怎么办？公式变形！$N^{d/2} = (\sqrt{N})^d$。
    既然 $d$ 不能除以 2，我把底数开根号（把底数 $N$ 的每个指数 $k$ 都除以 2）。因为 $k$ 都是偶数，除以 2 绝对是整数！
    用新的底数算 $(\sqrt{N})^d \pmod{10^9+7}$ 即可。

### 三、 极简重构版代码（采用最通用的方法二）

我把变量名全部改成了最直白的拼音/英文缩写，逻辑也做了极简平铺：

```cpp
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;

const ll MOD = 1e9 + 7;       // 算结果用的模数
const ll MOD_EXP = 1e9 + 6;   // 算指数用的模数 (MOD - 1)

// 快速幂模板: 求 base^exp % mod
ll qpow(ll base, ll exp, ll mod = MOD) {
    ll res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % mod;
        base = (base * base) % mod;
        exp /= 2;
    }
    return res;
}

int main() {
    int n;
    cin >> n;
    vector<ll> p(n), k(n); // p存质数，k存幂次
    for (int i = 0; i < n; i++) cin >> p[i] >> k[i];

    ll ans_cnt = 1;  // 约数个数
    ll ans_sum = 1;  // 约数之和
    ll ans_prod = 1; // 约数之积

    // ==========================================
    // 1. 求约数个数 (所有 k+1 相乘)
    // ==========================================
    for (int i = 0; i < n; i++) {
        ans_cnt = (ans_cnt * (k[i] + 1)) % MOD;
    }

    // ==========================================
    // 2. 求约数之和 (等比数列公式 + 逆元)
    // ==========================================
    for (int i = 0; i < n; i++) {
        ll fenzi = (qpow(p[i], k[i] + 1) - 1 + MOD) % MOD;
        ll fenmu = qpow(p[i] - 1, MOD - 2); // 逆元
        ans_sum = ans_sum * (fenzi * fenmu % MOD) % MOD;
    }

    // ==========================================
    // 3. 求约数之积 (利用公式 N^(d/2) 的分类讨论法)
    // ==========================================
    ll exp_cnt = 1; // 专门给指数用的约数个数 (对 MOD_EXP 取模)
    bool is_divided_by_2 = false; // 记录有没有除过 2

    // 算指数，顺便解决除以 2 的问题
    for (int i = 0; i < n; i++) {
        ll current_term = k[i] + 1;
        // 如果还没除过 2，且当前项是偶数，当场除以 2！
        if (!is_divided_by_2 && current_term % 2 == 0) {
            current_term /= 2;
            is_divided_by_2 = true;
        }
        exp_cnt = (exp_cnt * current_term) % MOD_EXP;
    }

    // 如果成功除过 2 (情况 A：不是完全平方数)
    if (is_divided_by_2) {
        for (int i = 0; i < n; i++) {
            ll base = qpow(p[i], k[i]); // 底数正常
            ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
        }
    } 
    // 如果没能除以 2 (情况 B：是完全平方数，所有 k 都是偶数)
    else {
        for (int i = 0; i < n; i++) {
            ll base = qpow(p[i], k[i] / 2); // 底数的指数除以2 (开方)
            ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
        }
    }

    cout << ans_cnt << " " << ans_sum << " " << ans_prod << "\n";
    return 0;
}
```

这样梳理后，变量名从 `has_even_k_plus_1` 变成了 `is_divided_by_2`，数学部分的 `fenzi` (分子) 和 `fenmu` (分母) 也更贴近中国学生的思考习惯，整体逻辑是不是清晰多了？

### 一、 约数之积【方法一：递推法】的彻底解剖

方法一的伟大之处在于：**它完全抛弃了 $N^{d/2}$ 这个带有除法的公式，而是像“搭积木”一样，通过旧的乘积一步步推出新的乘积。**

为了让你看懂，我们不看干巴巴的代数，直接用一个**具体的例子**来推演！

#### 1. 初始状态（只有第一块积木）
假设当前数字只有 $2^2$（即数字 4）。
它的约数有：$1, 2, 4$。
*   **当前的约数个数（`old_cnt`）** = 3
*   **当前的约数之积（`old_prod`）** = $1 \times 2 \times 4 = 8$

#### 2. 引入新质数（加入第二块积木）
现在，我们要乘上一个新的质因数 $3^1$（即引入 $p=3, k=1$）。
新数字变成了 $4 \times 3 = 12$。

**新数字的所有约数是怎么诞生的？**
它是由【旧约数集合】分别配上 $3^0$ 和 $3^1$ 组合而成的。我们把它们列出来看：

*   **第一批（配 $3^0$，即乘以 1）：** $1\times1, \quad 2\times1, \quad 4\times1$
*   **第二批（配 $3^1$，即乘以 3）：** $1\times3, \quad 2\times3, \quad 4\times3$

现在要把这 6 个新约数**全部乘起来**，得到新的 `new_prod`。仔细观察上面的两批数字，我们把它分成两部分来乘：

#### 3. 分两部分计算新乘积
**第一部分：只看旧约数本身的乘积（对应代码的 `term1`）**
你看上面两批数字，左边的 $1, 2, 4$ 被完整地写了两次（因为 $k=1$，配了 $3^0$ 和 $3^1$，所以写了 $k+1$ 次）。
所以，仅仅是这些旧约数相乘的结果就是：
$$(1 \times 2 \times 4) \times (1 \times 2 \times 4) = 8 \times 8 = 8^2$$
*   **总结规律：** 旧乘积被自己乘了 $(k+1)$ 次。
*   **代码表达：** `ll term1 = qpow(old_prod, k + 1, MOD);`

**第二部分：只看新质数 $3$ 贡献的乘积（对应代码的 `term2`）**
再看上面两批数字的右边，第一批没有 3，第二批有 3 个 3 相乘。
具体是怎么算出来的呢？
对于**任何一个**旧约数（比如 $1$），它都配了 $3^0$ 和 $3^1$，乘起来就是 $3^0 \times 3^1 = 3^{0+1} = 3^1$。（如果是 $k$，指数就是 $1+2+\dots+k = \frac{k(k+1)}{2}$）。
关键来了：旧约数一共有 `old_cnt` 个（这里是 3 个）。每一个旧约数，都会让新质数 $3$ 产生这么多乘积！
所以 3 的总指数是：$\frac{k(k+1)}{2} \times \text{old\_cnt}$。
套入我们的例子：$\frac{1 \times 2}{2} \times 3 = 3$。所以新质数贡献了 $3^3 = 27$。
*   **总结规律：** 新质数的底数是 $p$，指数是 $\frac{k(k+1)}{2} \times \text{old\_cnt}$。
*   **代码表达：**
    `ll power_p = (k * (k + 1) / 2) % MOD_EXP * old_cnt % MOD_EXP;`
    `ll term2 = qpow(p, power_p, MOD);`

**最后一步：合并**
`new_prod` = 第一部分 $\times$ 第二部分 = $8^2 \times 3^3 = 64 \times 27 = 1728$。
（你可以去算一下 12 的所有约数之积，恰好就是 1728！）

**为什么方法一能避开除以 2 的逆元死锁？**
因为在这个方法里，唯一的除以 2 发生在求等差数列 $\frac{k(k+1)}{2}$ 的时候。
在普通数学里，连续两个整数 $k$ 和 $k+1$ 相乘，**必定是一个偶数**。所以这个除以 2 是绝对安全的物理除法，算出来必定是个整数！算完这个整数，再去对 `MOD_EXP` 取模，根本不需要用到逆元！

### 二、 数学原理证明：为什么指数要对 $p-1$ 取模？

在计算大数次方 $A^B \pmod M$ 的时候（本题 $M = 10^9+7$），我们常常遇到指数 $B$ 极其庞大。
直觉上，我们可能会觉得：底数对 $M$ 取模，指数是不是也对 $M$ 取模？
**错！大错特错！指数绝对不能对 $M$ 取模。**

这个底层的数学原理，是由伟大的**费马小定理（Fermat's Little Theorem）**保证的。

#### 1. 费马小定理的内容
费马小定理说：如果 $M$ 是一个质数（本题 $10^9+7$ 是质数），并且底数 $A$ 不能被 $M$ 整除，那么必定有：
$$A^{M-1} \equiv 1 \pmod M$$
*举个小例子验证：$M=5, A=2$。$2^{5-1} = 2^4 = 16$。$16 \pmod 5 = 1$，完美成立。*

#### 2. 利用定理给指数“降维”
既然 $A^{M-1}$ 相当于 $1$，这就意味着：**在模 $M$ 的世界里，指数是以 $M-1$ 为周期在循环的！**

假设我们要算 $A^B \pmod M$。
我们可以把巨大的指数 $B$，拆解成 $M-1$ 的倍数，加上一个余数 $r$。
即：$B = q \times (M-1) + r$。
这里的余数 $r$，在数学上就等于 $B \pmod{M-1}$。

把这个拆解代入指数式子中：
$$A^B = A^{q \times (M-1) + r}$$
根据指数加法拆开：
$$= A^{q \times (M-1)} \times A^r$$
根据指数乘法变形：
$$= (A^{M-1})^q \times A^r$$

见证奇迹的时刻到了！
根据费马小定理，括号里的 $A^{M-1}$ 在对 $M$ 取模时，等价于 $1$。
所以式子变成了：
$$ \equiv 1^q \times A^r \pmod M$$
$$ \equiv A^r \pmod M$$

#### 3. 得出终极结论
这就严谨地证明了：
$$A^B \pmod M \equiv A^{B \pmod{M-1}} \pmod M$$

在本题中，要求结果对 $M = 10^9+7$ 取模。
那么计算到指数位置的所有变量（比如方法一里的 `old_cnt`，或者方法二里的 `exp_cnt`），**必须且只能对 $M-1$（即 $10^9+6$）取模！** 这就是代码中那个神秘的 `MOD_EXP = 1e9 + 6` 的根本由来。


太棒了！前面我们已经彻底弄懂了“为什么指数必须对 $10^9+6$ 取模”，这也正是**全局公式 $N^{d/2}$ 会陷入死锁的根本原因**（因为 $2$ 在模 $10^9+6$ 下没有逆元）。

现在，我们来隆重请出**方法二（分类降维法）**。
如果说方法一（递推法）是“绕路走”，那方法二就是**“正面硬刚，给公式做外科手术”**！

方法二的核心思想非常霸气：**既然在模运算的世界里不能除以 2，那我就在进入模运算之前，在普通的整数世界里，把这个 $\div 2$ 物理消灭掉！**

怎么消灭？根据数字 $N$ 的奇偶性特征，世界上所有的数字绝对会落入以下两种情况之一。

---

### 突破口：看所有质因数的指数 $k$

我们知道，约数总个数 $d = (k_1+1) \times (k_2+1) \times \dots \times (k_n+1)$。
我们要算的是 $\frac{d}{2}$。

#### 情况 A：算指数时“有便宜可占”（$N$ 不是完全平方数）

**特征是什么？**
只要 $N$ 的所有质因数的指数 $k$ 里面，**哪怕只有一个奇数**（比如 $k_1 = 3$），那么对应的 $(k_1+1)$ 就会变成**偶数**（$3+1=4$）。

**怎么动手术？**
在把这些 $(k+1)$ 乘起来去算 $d$ 的过程中，我们紧紧盯着每一个项。
只要碰到**第一个偶数**，我们二话不说，**当场把它除以 2！**

*   **举个例子：** $N = p_1^3 \times p_2^2$。
    它的 $d = (3+1) \times (2+1) = 4 \times 3 = 12$。正常除以 2 应该是 6。
    按我们的手术方法：碰到第一个项 $(3+1)=4$ 是偶数，当场除以 2 变成 2。然后再乘以后面的 3，得到 $2 \times 3 = 6$。完美！
*   **物理意义：** 因为乘法满足交换律和结合律，提前把其中一个偶数因子除以 2，就等于把最终的乘积除以了 2。
*   **结果：** 这样算出来的 `exp_cnt`，在取模之前就已经成功除过 2 了，它是完美合法的 $\frac{d}{2} \pmod{10^9+6}$。
*   **最后计算：** 底数不变，直接算 $N^{\text{exp\_cnt}} \pmod{10^9+7}$。危机解除！

#### 情况 B：算指数时“铁板一块”（$N$ 是完全平方数）

**特征是什么？**
如果 $N$ 的所有指数 $k$ **全都是偶数**（比如 $k_1=2, k_2=4$），那么所有的 $(k+1)$ 全都会变成奇数。
奇数乘奇数永远是奇数，这就导致最终的 $d$ 是一个奇数。
奇数除以 2 变成小数了！在指数上我们绝对不能出现小数！

**怎么动手术？（乾坤大挪移）**
既然指数 $d$ 铁板一块，死活不能除以 2，那我们就利用初中数学的指数定律：
$$N^{\frac{d}{2}} = \left( N^{\frac{1}{2}} \right)^d = (\sqrt{N})^d$$

绝妙的地方来了！
因为现在是情况 B，所有的 $k$ 都是偶数！既然所有的 $k$ 都是偶数，那我们把底数 $N$ 开根号，不就等于把**每一个 $k$ 都除以 2** 吗？偶数除以 2，绝对是整数！

*   **举个例子：** $N = p_1^2 \times p_2^4$。
    它的 $d = (2+1) \times (4+1) = 3 \times 5 = 15$。（果然是奇数，不能除以 2）。
    我们不碰 $d$，让 $d$ 就保持 15。
    我们去搞底数 $N$：把 $p_1^2$ 的指数除以 2 变成 $p_1^1$；把 $p_2^4$ 的指数除以 2 变成 $p_2^2$。新的底数变成了 $p_1^1 \times p_2^2$（这就是 $\sqrt{N}$）。
*   **物理意义：** 我们把“除以 2”这个艰巨的任务，**从指数身上，转移到了底数身上**。
*   **结果：** 指数 $d$ 正常对 $10^9+6$ 取模，底数由于 $k$ 都是偶数，顺利开完根号。
*   **最后计算：** 用新的底数算 $(\sqrt{N})^d \pmod{10^9+7}$。危机再次解除！

### 方法二大总结

方法二的绝妙之处在于**“分类转嫁危机”**：

1.  **能拿指数开刀的时候：** 就找准指数连乘里的第一个偶数，砍掉一半。（情况 A）
2.  **指数拿刀砍不动的时候：** 必定是因为底数的所有指数都是偶数，那就转头去砍底数，把底数的指数全砍掉一半。（情况 B）

因为自然数不是奇数就是偶数，所以这两种情况**互斥且完全穷尽**。这就保证了这个数学逻辑是无懈可击的。

```cpp
    ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
} 
// 如果没能除以 2 (情况 B)
else {
    ll base = qpow(p[i], k[i] / 2); // 指数不动，底数的 k 被砍掉一半
    ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
}
```

这就是 CSES 官方标答（也是顶级算法竞赛选手最爱用）的思路。它没有用复杂的推导，仅仅利用了奇偶性和基础代数恒等式，就破解了模运算下无逆元的世纪难题！
