### 一、 约数之和（Sum of Divisors）的数学原理

我们要算一个数所有约数加起来的总和。
假设这个数字是 $N = 12$。它的质因数分解是 $12 = 2^2 \times 3^1$。
$12$ 的约数有：$1, 2, 4, 3, 6, 12$。加起来是 $28$。

**1. 乘法分配律的魔法**
数学家发现，不需要把所有约数一个个找出来相加，利用**乘法分配律**可以直接搞定。
我们把 $2$ 的所有幂次写在一个括号里，把 $3$ 的所有幂次写在另一个括号里相乘：
$$(2^0 + 2^1 + 2^2) \times (3^0 + 3^1)$$
展开这个式子，你会发现它完美对应了所有约数：
$$= (1 + 2 + 4) \times (1 + 3)$$
$$= 1\times1 + 1\times3 + 2\times1 + 2\times3 + 4\times1 + 4\times3$$
$$= 1 + 3 + 2 + 6 + 4 + 12$$
左边算出来是 $7 \times 4 = 28$，完美吻合！

**2. 转化为等比数列求和**
所以，对于任意数字 $N = p_1^{k_1} \times p_2^{k_2} \dots$，约数之和就是：
$$(1 + p_1 + p_1^2 + \dots + p_1^{k_1}) \times (1 + p_2 + \dots + p_2^{k_2}) \dots$$

括号里的一长串，就是高中的**等比数列求和**。
公式为：$1 + p + p^2 + \dots + p^k = \frac{p^{k+1} - 1}{p - 1}$

**3. 代码怎么写？（逆元的出场）**
题目要求结果对 $10^9+7$ 取模。模运算里**不能直接用除法**，除以 $(p-1)$ 必须变成**乘以 $(p-1)$ 的逆元**。
逆元怎么求？费马小定理告诉我们，求 $X$ 的逆元，就是算 $X^{10^9+5} \pmod{10^9+7}$。

代码极其简单（精简变量名后）：
```cpp
// 算分子: (p^(k+1) - 1) % MOD
ll fenzi = (qpow(p, k + 1, MOD) - 1 + MOD) % MOD;
// 算分母的逆元: (p - 1)^(MOD - 2) % MOD
ll fenmu = qpow(p - 1, MOD - 2, MOD); 
// 乘进总和里
ans_sum = ans_sum * (fenzi * fenmu % MOD) % MOD;
```

### 二、 约数之积（Product of Divisors）的两座大山

约数之积的难点在于：**全局公式是 $N^{d/2}$（$d$ 是约数总个数）。要在指数上除以 2，但在 $\pmod{10^9+6}$ 的世界里，2 没有逆元，除法失效！**

为了绕开这个“无法除以 2”的死锁，有两种极其聪明的方法。

#### 方法一：递推法（像滚雪球一样积累）

**核心思想：既然最后一起算会卡在除以 2，那我就每拿到一个质因数，就把当前的乘积更新一次。**

假设我们刚才已经处理完了一些质数，算出的旧乘积叫 `old_prod`，旧的约数个数叫 `old_cnt`。
现在我们引入了一个新的质数 $p$，它的幂次是 $k$。新的乘积 `new_prod` 由两部分构成：

1.  **旧乘积被放大了：**
    原来算好的 `old_prod`，现在要分别跟新质数的 $p^0, p^1, p^2 \dots p^k$ 结合。
    这意味着 `old_prod` 连乘了 $k+1$ 次。
    **产生的部分 1：`qpow(old_prod, k + 1, MOD)`**
2.  **新质数 $p$ 自己产生的贡献：**
    新质数引入了 $p^1 \times p^2 \times p^3 \dots \times p^k$。
    底数相同，指数相加：$1 + 2 + \dots + k = \frac{k(k+1)}{2}$。
    注意！这个 $\frac{k(k+1)}{2}$ 是普通的数学计算，**相邻两数相乘必为偶数，绝对能被 2 整除！** 我们在这里除以 2 是安全的。
    并且，这个新贡献会对旧的每一种组合（共 `old_cnt` 种）都发生一次。
    **产生的部分 2 的指数：`power_p = (k * (k + 1) / 2) % MOD_EXP * old_cnt % MOD_EXP`**
    **产生的部分 2：`qpow(p, power_p, MOD)`**

把这两部分乘起来，就是新的乘积！完美避开了在取模后除以 2 的窘境。

#### 方法二：分类讨论法（直接给公式动手术）

**核心思想：我非要用 $N^{d/2}$ 这个公式！既然模运算下不能除以 2，那我在取模之前、在普通的整数世界里，把这个 2 给约掉不就行了？**

因为 $d = (k_1+1) \times (k_2+1) \times \dots$，我们分两种情况看这个 $d$：

*   **情况 A：不是完全平方数**
    这意味着，这些 $(k+1)$ 里面，**肯定至少有一个是偶数**。
    那太好了！在用 `for` 循环把它们乘起来算 $d$ 的时候，一旦碰到**第一个**偶数，我当场把它除以 2。
    这样算出来的最终结果 `exp_cnt`，实际上就已经提前除过 2 了。
    直接算 $N^{\text{exp\_cnt}} \pmod{10^9+7}$ 即可。
*   **情况 B：是完全平方数**
    这意味着所有的 $k$ 都是偶数，导致所有的 $(k+1)$ 都是奇数。奇数乘奇数还是奇数，$d$ 是奇数，没法除以 2。
    怎么办？公式变形！$N^{d/2} = (\sqrt{N})^d$。
    既然 $d$ 不能除以 2，我把底数开根号（把底数 $N$ 的每个指数 $k$ 都除以 2）。因为 $k$ 都是偶数，除以 2 绝对是整数！
    用新的底数算 $(\sqrt{N})^d \pmod{10^9+7}$ 即可。

### 三、 极简重构版代码（采用最通用的方法二）

我把变量名全部改成了最直白的拼音/英文缩写，逻辑也做了极简平铺：

```cpp
#include <iostream>
#include <vector>
using namespace std;
using ll = long long;

const ll MOD = 1e9 + 7;       // 算结果用的模数
const ll MOD_EXP = 1e9 + 6;   // 算指数用的模数 (MOD - 1)

// 快速幂模板: 求 base^exp % mod
ll qpow(ll base, ll exp, ll mod = MOD) {
    ll res = 1;
    base %= mod;
    while (exp > 0) {
        if (exp % 2 == 1) res = (res * base) % mod;
        base = (base * base) % mod;
        exp /= 2;
    }
    return res;
}

int main() {
    int n;
    cin >> n;
    vector<ll> p(n), k(n); // p存质数，k存幂次
    for (int i = 0; i < n; i++) cin >> p[i] >> k[i];

    ll ans_cnt = 1;  // 约数个数
    ll ans_sum = 1;  // 约数之和
    ll ans_prod = 1; // 约数之积

    // ==========================================
    // 1. 求约数个数 (所有 k+1 相乘)
    // ==========================================
    for (int i = 0; i < n; i++) {
        ans_cnt = (ans_cnt * (k[i] + 1)) % MOD;
    }

    // ==========================================
    // 2. 求约数之和 (等比数列公式 + 逆元)
    // ==========================================
    for (int i = 0; i < n; i++) {
        ll fenzi = (qpow(p[i], k[i] + 1) - 1 + MOD) % MOD;
        ll fenmu = qpow(p[i] - 1, MOD - 2); // 逆元
        ans_sum = ans_sum * (fenzi * fenmu % MOD) % MOD;
    }

    // ==========================================
    // 3. 求约数之积 (利用公式 N^(d/2) 的分类讨论法)
    // ==========================================
    ll exp_cnt = 1; // 专门给指数用的约数个数 (对 MOD_EXP 取模)
    bool is_divided_by_2 = false; // 记录有没有除过 2

    // 算指数，顺便解决除以 2 的问题
    for (int i = 0; i < n; i++) {
        ll current_term = k[i] + 1;
        // 如果还没除过 2，且当前项是偶数，当场除以 2！
        if (!is_divided_by_2 && current_term % 2 == 0) {
            current_term /= 2;
            is_divided_by_2 = true;
        }
        exp_cnt = (exp_cnt * current_term) % MOD_EXP;
    }

    // 如果成功除过 2 (情况 A：不是完全平方数)
    if (is_divided_by_2) {
        for (int i = 0; i < n; i++) {
            ll base = qpow(p[i], k[i]); // 底数正常
            ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
        }
    } 
    // 如果没能除以 2 (情况 B：是完全平方数，所有 k 都是偶数)
    else {
        for (int i = 0; i < n; i++) {
            ll base = qpow(p[i], k[i] / 2); // 底数的指数除以2 (开方)
            ans_prod = (ans_prod * qpow(base, exp_cnt)) % MOD;
        }
    }

    cout << ans_cnt << " " << ans_sum << " " << ans_prod << "\n";
    return 0;
}
```

这样梳理后，变量名从 `has_even_k_plus_1` 变成了 `is_divided_by_2`，数学部分的 `fenzi` (分子) 和 `fenmu` (分母) 也更贴近中国学生的思考习惯，整体逻辑是不是清晰多了？
