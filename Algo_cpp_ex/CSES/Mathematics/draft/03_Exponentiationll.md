### 为什么不需要特判 `if (a == 0)`？（证明过程）

之前提到的特判逻辑是：
*   $a=0, b=0, c>0 \implies 0^{0^c} \implies 0^0 = 1$
*   $a=0, b=0, c=0 \implies 0^{0^0} \implies 0^1 = 0$
*   $a=0, b>0 \implies 0^{\text{正数}} = 0$

让我们用你的标准 `qpow` 迭代模板（或递归模板）来**干跑（Dry Run）**一下，看看如果不写 `if (a == 0)`，程序会发生什么。

**标准模板行为前提：**
任何规范的快速幂，只要满足 `qpow(0, 0, M) == 1` 且 `qpow(0, k, M) == 0` (当 $k>0$ 时)，就能自动处理这些坑！

#### 情况 1：$a=0, b=0, c>0$
1. 计算指数：`exp = qpow(0, c, 1e9+6)`。
   因为 $c > 0$，所以进入循环，底数 `0` 会乘入结果，最终 `exp = 0`。
2. 计算最终结果：`ans = qpow(0, exp, 1e9+7)` 即 `qpow(0, 0, 1e9+7)`。
   因为指数为 `0`，直接触发 `if(exp == 0)` / `while(exp)` 进不去，**返回 `1`**。
**结果正确！完美符合题意。**

#### 情况 2：$a=0, b=0, c=0$
1. 计算指数：`exp = qpow(0, 0, 1e9+6)`。
   因为指数为 `0`，直接**返回 `1`**。
2. 计算最终结果：`ans = qpow(0, 1, 1e9+7)`。
   因为指数 $1 > 0$，进入循环，底数 `0` 乘入结果，**返回 `0`**。
**结果正确！**

#### 情况 3：$a=0, b>0, c \ge 0$
1. 计算指数：`exp = qpow(b, c, 1e9+6)`。
   因为 $b>0$，这里算出来无论如何 `exp` 都是大于 `0` 的（除非 $b$ 恰好是 $10^9+6$ 的倍数，但这题数据范围 $b \le 10^9$，所以不可能）。
2. 计算最终结果：`ans = qpow(0, exp, 1e9+7)`。
   因为指数 `exp > 0`，底数 `0` 乘入结果，**返回 `0`**。
**结果正确！**

### 终极精简版模板（ICPC 极简风格）
这段代码去掉了特判，利用算法天然的完备性处理了一切边界情况，是赛场上最不容易写出 Bug 的版本。

```cpp
#include <iostream>
using namespace std;
typedef long long ll;

const ll MOD = 1e9 + 7;

// 肌肉记忆：标准快速幂模板 (自带防御性 % mod，完美处理 0^0=1)
ll qpow(ll base, ll exp, ll mod) {
    ll res = 1 % mod; // 防御 m=1 的极端情况
    base %= mod;
    while (exp > 0) {
        if (exp & 1) res = res * base % mod;
        base = base * base % mod;
        exp >>= 1;
    }
    return res;
}

int main() {
    // IO 优化
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    if (cin >> n) {
        while (n--) {
            ll a, b, c;
            cin >> a >> b >> c;
            
            // 两行代码解决战斗：
            // 1. 费马小定理，指数对 (MOD - 1) 取模
            ll exp = qpow(b, c, MOD - 1);
            // 2. 算最终结果对 MOD 取模
            ll ans = qpow(a, exp, MOD);
            
            cout << ans << "\n";
        }
    }
    return 0;
}
```

### 给你的复习小贴士（关于 `__int128`）
你贴出的第一段模板中使用了 `__int128`，这里解释一下为什么：
*   当模数 `MOD` 达到 $10^{18}$ 级别时，两个 `long long` 相乘（$10^{18} \times 10^{18} = 10^{36}$）会直接爆 `long long` 甚至 `unsigned long long`。这时候必须强转 `__int128` 进行中间过程的乘法。
*   但本题 `MOD = 1e9+7`，两个 `MOD` 相乘最大是 $10^{18}$，刚好在 `long long` 的安全范围内，所以可以直接用 `long long`，避免了 `__int128` 常数稍大的问题。

### 第一步：明确理论基石 —— 费马小定理 (Fermat's Little Theorem)

**定理内容：**
如果 $p$ 是一个质数，且整数 $a$ 和 $p$ 互质（即 $\gcd(a, p) = 1$），那么：
$$a^{p-1} \equiv 1 \pmod p$$

*(注：在 $10^9+7$ 的语境下，因为它是质数，只要 $a$ 不是 $10^9+7$ 的倍数，这个条件就必然成立。)*

### 第二步：设定目标与引入带余除法

**我们的目标：**
我们要计算一个巨大的幂次：$a^X \pmod p$ （在题目中 $X = b^c$）。

**带余除法（Division Algorithm）：**
对于任何整数 $X$，我们都可以把它除以 $(p-1)$，得到一个商 $k$ 和一个余数 $r$。
数学表达式写为：
$$X = k \cdot (p-1) + r$$
其中，余数的范围是 $0 \le r < p-1$。
更直白地说，这个余数 $r$ 其实就是 **$X \pmod{p-1}$**。

### 第三步：代入并拆解指数

现在，我们把 $X$ 的表达式代入到我们要求的 $a^X$ 中：
$$a^X = a^{k \cdot (p-1) + r}$$

根据中学学过的**同底数幂乘法法则**（$a^{m+n} = a^m \cdot a^n$），把它拆开：
$$a^X = a^{k \cdot (p-1)} \cdot a^r$$

再根据**幂的乘方法则**（$a^{m \cdot n} = (a^m)^n$），进一步把左边变形：
$$a^X = (a^{p-1})^k \cdot a^r$$

### 第四步：在模 $p$ 意义下施展魔法

现在，我们在等式两边同时套上 $\pmod p$。

根据第一步的**费马小定理**，我们知道 $\color{red}a^{p-1} \equiv 1 \pmod p$。
所以，我们可以把式子中的 $a^{p-1}$ 直接替换成 $1$：
$$a^X \equiv (\color{red}1\color{black})^k \cdot a^r \pmod p$$

因为 $1$ 的任何次幂都等于 $1$（即 $1^k = 1$），所以式子瞬间崩塌式简化：
$$a^X \equiv 1 \cdot a^r \pmod p$$
$$a^X \equiv a^r \pmod p$$

### 第五步：得出最终结论

最后，把余数 $r$ 替换回它原本的含义 $r = X \pmod{p-1}$，我们就得到了著名的降幂公式：

$$a^X \equiv a^{X \pmod{p-1}} \pmod p$$

**证明完毕。** $\blacksquare$

### ⚠️ ICPC 赛场避坑指南（极其重要）

既然你看到了严格的推导，就一定能发现这个推导过程中的一个**致命漏洞**：
在【第四步】中，我们把 $a^{p-1}$ 替换成 $1$ 的前提是：**$\gcd(a, p) = 1$（即 $a$ 不能是 $p$ 的倍数）。**

如果 $a$ 是 $p$ 的倍数（在取模的意义下，也就是 **$a \equiv 0 \pmod p$**），会发生什么？

**举个致命的反例：**
假设模数 $p = 7$，底数 $a = 0$。指数 $X = 6$。
*   **正确的数学结果**：$0^6 \pmod 7 = \mathbf{0}$。
*   **套用降幂公式**：$0^6 \equiv 0^{6 \pmod 6} \equiv 0^0 \equiv \mathbf{1} \pmod 7$。

**结果冲突了！公式在这个特例下失效了！**
这也就意味着，我在上一个回答中推演的那个“不需要特判的完美情况”，**其实在一种极其极端的条件下会挂掉**：当 $a=0$，且指数 $b^c$ 恰好是 $p-1$ 的倍数时，套用普通降幂公式会输出 $1$，但正确答案应该是 $0$。

*(这说明你之前的 `if (a == 0)` 特判其实是防住了这个极其刁钻的漏洞，你最初贴的代码是非常严谨的！)*

### 赛场终极解决方案：扩展欧拉定理（无限降幂公式）

为了在赛场上彻底不写特判、并且百分百保证正确，数论中有一个更强大的定理，叫做**扩展欧拉定理**。它的公式是（无论 $a$ 和 $p$ 是否互质都成立）：

当 $X \ge \phi(p)$ 时：
$$a^X \equiv a^{X \pmod{\phi(p)} + \phi(p)} \pmod p$$

*(注：对于质数 $p$，欧拉函数 $\phi(p) = p-1$)*

也就是说，只要指数比较大，我们取模后**不要让它变成 $0$**，而是给它**强行加上一个 $\phi(p)$** 作为保底。这样 $0^{X \bmod \phi(p) + \phi(p)}$ 就绝对不会变成 $0^0$，依然是 $0^{\text{正数}} = 0$。

通过这次推导，你不仅掌握了降幂公式的由来，还摸清了它在 $a=0$ 时的阿喀琉斯之踵。这就是推导定理的最大价值！
