# Stair Game

## Problem Description
There is a staircase consisting of $n$ stairs, numbered $1,2,\dots,n$. Initially, each stair has some number of balls.
There are two players who move alternately. On each move, a player chooses a stair $k$ where $k \neq 1$ and it has at least one ball. Then, the player moves any number of balls from stair $k$ to stair $k-1$. The player who moves last wins the game.
Your task is to find out who wins the game when both players play optimally.
Note that if there are no possible moves at all, the second player wins.

有一个由 $n$ 级台阶组成的楼梯，编号为 $1,2,\dots,n$。最初，每级台阶上都有一定数量的小球。
有两名轮流行动的玩家。在每一步行动中，玩家选择一个至少有一个小球的台阶 $k$（其中 $k \neq 1$）。然后，该玩家将任意数量的小球从台阶 $k$ 移动到台阶 $k-1$。最后移动的玩家赢得游戏。
你的任务是找出在双方都采用最优策略的情况下，谁会赢得游戏。
注意，如果一开始没有任何合法的移动，则后手玩家获胜。

## Input
The first input line has an integer $t$: the number of tests. After this, $t$ test cases are described:
The first line contains an integer $n$: the number of stairs.
The next line has $n$ integers $p_1,p_2,\dots,p_n$: the initial number of balls on each stair.

第一行输入包含一个整数 $t$：测试用例的数量。之后描述 $t$ 个测试用例：
每个用例的第一行包含一个整数 $n$：台阶的数量。
下一行包含 $n$ 个整数 $p_1,p_2,\dots,p_n$：每级台阶上初始的小球数量。

## Output
For each test, print "first" if the first player wins the game and "second" if the second player wins the game.

对于每个测试用例，如果先手玩家获胜则输出 "first"，如果后手玩家获胜则输出 "second"。

## Constraints
$1 \le t \le 2 \cdot 10^5$
$1 \le n \le 2 \cdot 10^5$
$0 \le p_i \le 10^9$
the sum of all $n$ is at most $2 \cdot 10^5$

## Example
**Input:**
```
3
3
0 2 1
4
1 1 1 1
2
5 3
```

**Output:**
```
first
second
first
```


太牛了！你已经不知不觉刷到了博弈论中极其著名的一个进阶模型——**阶梯博弈（Staircase Nim）**。

如果你看懂了上一题中“学人精（镜像模仿）”和“黑洞（无效操作）”的概念，这道题你会觉得**爽到飞起**。因为它完全就是这两个概念的终极融合！

我们直接来扒掉这道题的底裤。

---

### 一、 核心结论（一秒破题）

别管它有多少级台阶，也别管上面的球怎么挪来挪去。
**你只需要把所有【偶数台阶】（第2、4、6、8...级）上的球的数量，全部异或起来！**
*   **异或和 $\neq 0$**：先手必胜（`first`）。
*   **异或和 $= 0$**：后手必胜（`second`）。

【奇数台阶】（第1、3、5、7...级）上的球？**全是障眼法，连看都不用看！**

---

### 二、 为什么？（底层逻辑：垃圾桶与学人精）

这道题的规则是：把球从第 $k$ 级挪到第 $k-1$ 级。最后挪不了的人输。
我们给这些台阶重新起个名字，你瞬间就能秒懂：

#### 1. 第 1 级台阶 = “垃圾桶”
题目说球挪到第 1 级就不能再动了。这意味着什么？
这意味着第 1 级台阶就是一个**“无底垃圾桶”**。任何球只要掉进这里，就等同于在游戏里**被彻底销毁了**。

#### 2. 第 2 级台阶 = “标准 Nim 游戏”
如果球在第 2 级，你一挪，它就掉进第 1 级（垃圾桶）销毁了。
这不就是标准的 Nim 游戏吗？**“从第 2 级挪走 $x$ 个球”，完美等价于“从石子堆里拿走 $x$ 颗石子扔掉”。**

#### 3. 第 3 级台阶 = “无用的障眼法”（学人精大显身手）
如果球在第 3 级，有人把它挪到了第 2 级。这相当于给第 2 级的 Nim 堆**增加**了石子！
等一下，标准的 Nim 游戏是不允许增加石子的，这怎么算？

这时候，**“学人精”防守策略**登场了！
假设你是高手，局面原本是必胜的。对手气急败坏，把 5 个球从第 3 级推到了第 2 级，企图打乱你的计划。
你该怎么做？
**你只需要当个“学人精快递员”，在你的回合，立刻把这 5 个球从第 2 级推到第 1 级（垃圾桶）里去！**

你看，对手从奇数推到偶数，你就顺手从偶数推到奇数（垃圾桶）。这一套连招下来，第 2 级台阶上的球数**根本没有变化**！对手白白浪费了一回合，而局面的胜负态完全没有改变。

#### 4. 推广到所有台阶
*   **偶数台阶（2, 4, 6...）**：把球从这里推到奇数台阶，就等于把球推进了“中转垃圾桶”。对手无法阻止。这才是**真正有杀伤力的 Nim 堆**。
*   **奇数台阶（1, 3, 5...）**：把球从这里推到偶数台阶，对手永远可以当“学人精”，立刻把这些球再推下一级。所以，奇数台阶上的球，**对胜负毫无影响，全是废球**。

**终极等效：**
这个花里胡哨的阶梯游戏，**完美等价于：只有偶数台阶上存在的普通 Nim 游戏！**

---

### 三、 样例推导验证

我们用你的“新眼睛”去看看题目的三个样例。

**Test 1**:
*   `n = 3`，台阶球数：`0 2 1` (分别是第1、2、3级)
*   只看偶数台阶：第 2 级有 `2` 个球。
*   异或和：`2`。不为 0。
*   **结果**：`first`。（一秒出答案，完全不需要管第3级的那个球）

**Test 2**:
*   `n = 4`，台阶球数：`1 1 1 1`
*   只看偶数台阶：第 2 级有 `1` 个，第 4 级有 `1` 个。
*   异或和：`1 ^ 1 = 0`。
*   **结果**：`second`。

**Test 3**:
*   `n = 2`，台阶球数：`5 3`
*   只看偶数台阶：第 2 级有 `3` 个。
*   异或和：`3`。不为 0。
*   **结果**：`first`。

样例全中，且毫无计算压力！

### 四、 C++ 代码实现

代码极致简单。因为只有偶数台阶有用，我们在读入的时候，只需要判断台阶的编号是不是偶数，如果是，就把它异或起来。

```cpp
#include <iostream>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    int xor_sum = 0;
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        // 核心魔法：只关注偶数级台阶！
        if (i % 2 == 0) {
            xor_sum ^= x;
        }
    }
    
    if (xor_sum != 0) {
        cout << "first\n";
    } else {
        cout << "second\n";
    }
}

int main() {
    // 快速 I/O 依然是处理大规模测试用例的必需品
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

### 五、 总结提升

这道题叫做 **Staircase Nim（阶梯博弈）**，是组合博弈论中除了普通 Nim 之外考得最多的变形之一。

它教会了我们博弈论中极为重要的一种降维思想：**寻找可抵消的操作**。

在复杂的博弈游戏中，很多操作看起来能改变状态，但如果这种操作能被对手**无损镜像复原**（就像把奇数台阶的球推到偶数，对手能立刻把它推回奇数），那么这种操作就是**伪操作**，产生这种操作的石子就是**废石子**。

把伪操作和废石子全部剔除，极其复杂的游戏瞬间就会现出它的原形——一个最基础的异或 Nim 游戏！



# 代数推理逻辑
完全理解你的困惑！对于习惯了代数公式和方程的人来说，文字游戏、概率题或者像博弈论这种带有“操作过程”的题目，确实会让人觉得无从下手。因为**代数是静态的等式，而游戏是动态的状态转移**。

既然你更习惯代数和逻辑推理，那我们就**把通俗的比喻全部扔掉**，用纯粹的**“状态机”和“代数变量”**来重新推导这道题。

我会教你一种叫**“寻找不变子空间（有效变量）”**的方法，这正是数学系或者搞算法竞赛的人，把文字题抽象成代数模型的核心技巧。

---

### 第一步：严谨定义“标准 Nim 游戏”的数学模型

在抽象这道题之前，我们先用代数语言把“标准 Nim 游戏”写出来，作为我们的**目标公式**。

*   **变量集合**：有 $m$ 个独立的变量 $H_1, H_2, \dots, H_m$。
*   **合法操作**：选择一个变量 $H_i > 0$，将其减小为一个非负整数 $H_i'$（即 $H_i \to H_i - x$）。
*   **注意**：减去的数字 $x$ **直接消失了**，不会加到其他变量上。变量**绝对不允许增加**。
*   **终点**：所有 $H_i = 0$。
*   **解法**：当且仅当 $H_1 \oplus H_2 \oplus \dots \oplus H_m \neq 0$ 时先手胜。

---

### 第二步：将“阶梯游戏”翻译成代数状态方程

现在看我们的题目。
*   **变量集合**：有 $n$ 个变量 $S_1, S_2, S_3, \dots, S_n$（代表台阶上的球数）。
*   **合法操作**：选择一个 $k \ge 2$，且 $S_k > 0$。取走 $x$ 个球（$0 < x \le S_k$）。
*   **状态方程**：
    *   $S_k \to S_k - x$ （当前变量减小）
    *   $S_{k-1} \to S_{k-1} + x$ （**前一个变量增加！**）

**矛盾出现了！**
这就你的大脑卡壳的地方：标准 Nim 里的 $x$ 是直接消失的，而这里的 $x$ 没有消失，它转移到了 $S_{k-1}$！而且标准 Nim 不允许变量增加，这里 $S_{k-1}$ 却增加了。
**因为有变量增加，所以这显然不是标准的 Nim。**

---

### 第三步：寻找“代数等效” —— 降维打击

怎么把“会增加的变量”消掉？我们通过奇偶性把变量分成两组。

**集合 E (Even，偶数台阶)**：$S_2, S_4, S_6 \dots$
**集合 O (Odd，奇数台阶)**：$S_1, S_3, S_5 \dots$

现在我们来看看，这两种操作对应的代数方程是什么：

#### 操作 A：移动偶数台阶（$S_{even} \to S_{odd}$）
假设我们把 $S_2$ 的 $x$ 个球移到 $S_1$。
*   方程：$S_2 \to S_2 - x$
*   方程：$S_1 \to S_1 + x$

**关键逻辑**：注意看，集合 E 里的变量 $S_2$ **减小了**，而增加的是集合 O 里的 $S_1$。如果我们在心里**单方面屏蔽掉集合 O**（假设集合 O 里的数字对胜负完全没影响），那么操作 A 在集合 E 看来，就是纯粹的：
**$S_2 \to S_2 - x$ （这完全符合标准 Nim 的要求！数字直接消失了！）**

#### 操作 B：移动奇数台阶（$S_{odd} \to S_{even}$）
假设对手把 $S_3$ 的 $y$ 个球移到了 $S_2$。
*   方程：$S_3 \to S_3 - y$
*   方程：$S_2 \to S_2 + y$

**关键逻辑**：糟糕！集合 E 里的 $S_2$ **增加了 $y$**！这违反了 Nim 游戏不能增加的规则。
但是，博弈论允许我们采用**策略**。既然 $S_2$ 增加了 $y$，我能不能强制把它减回去？
**能！** 在我的回合，我强制执行操作 A：把刚才加到 $S_2$ 的那 $y$ 个球，移到 $S_1$。
代入方程看看这两步的合并结果：
1. 对手：$S_2 \to S_2 + y$
2. 我：$S_2 \to (S_2 + y) - y = S_2$
**合并结果：集合 E 里的变量经历了两个回合后，净变化量为 0！**

---

### 第四步：完成逻辑闭环

现在我们把所有代数逻辑串起来：

1.  **假设**：我们宣告“集合 O（奇数台阶）全是垃圾数据，不计入胜负”。我们将 $S_2, S_4, S_6 \dots$ 视作标准 Nim 游戏的 $H_1, H_2, H_3 \dots$。
2.  **我的回合**：我只操作集合 E（偶数台阶），执行 $S_{even} \to S_{even} - x$。这完全满足标准 Nim 规则。我把减去的值扔进集合 O，不管它了。
3.  **对手的回合**：
    *   **情况 1**：对手也操作集合 E，那他也满足标准 Nim 规则，游戏继续。
    *   **情况 2**：对手操作集合 O（想把数字加到集合 E 里来捣乱）。根据我们在“操作 B”里的推导，我立刻在下个回合把它踢出集合 E，使得集合 E 的净变化为 0。
4.  **终点**：题目规定 $S_1$ 不能移动。所以球一旦到了 $S_1$ 就死了。所有的球最终都会流向 $S_1$（由于每次都向左移）。所以游戏必定会结束。

**严谨的数学结论：**
因为“对手试图给偶数变量增加数值”的这种行为，在代数上总是可以被我们**抵消成 $+y -y = 0$**，所以【奇数台阶】对游戏状态方程的影响是**可被完全抹除的 (Cancelable)**。
既然可以被完全抹除，这就意味着这个游戏的**核心代数空间**仅仅由【偶数台阶】构成。

因此，原本复杂的互相转移方程，在去除了冗余维度（奇数台阶）后，完美坍缩成了：
**目标公式：$S_2 \oplus S_4 \oplus S_6 \dots \neq 0$ 则先手胜。**

---

### 总结：以后遇到文字题怎么抽象？

习惯代数的你，以后遇到这类题目，不要去脑补“人怎么拿球”、“怎么模仿”这种画面感，那是给直觉型选手用的。

你需要做的是**建立代数状态机**：
1.  **列出所有状态变量**（比如 $S_1 \dots S_n$）。
2.  **写出所有操作的代数变化式**（比如 $S_k \to S_k-x, S_{k-1} \to S_{k-1}+x$）。
3.  **寻找“目标模型”**（我知道标准 Nim 只有减法，也就是只有 $X \to X-x$）。
4.  **寻找“不变量/抵消项”**（这个变化式里有加法，我能不能找到一种配对，使得加法立刻被减法抵消：$+x -x = 0$？如果能，那个产生加法的变量就是一个冗余变量）。
5.  **剔除冗余变量，套用公式**。

一旦你用这五步剥开了文字的外衣，所有的博弈题在你的眼里，就会变成一堆可以直接化简的代数方程了。
