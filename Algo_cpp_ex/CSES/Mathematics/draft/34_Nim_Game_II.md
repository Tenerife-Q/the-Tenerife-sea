# Nim Game II

## Problem Description
There are $n$ heaps of sticks and two players who move alternately. On each move, a player chooses a non-empty heap and removes 1, 2, or 3 sticks. The player who removes the last stick wins the game.
Your task is to find out who wins if both players play optimally.

有 $n$ 堆棍子和两名轮流行动的玩家。在每一步行动中，玩家选择一个非空的堆并从中取走 1、2 或 3 根棍子。取走最后一根棍子的玩家将赢得游戏。
你的任务是找出在双方都采用最优策略的情况下，谁会赢得游戏。

## Input
The first input line contains an integer $t$: the number of tests. After this, $t$ test cases are described:
The first line contains an integer $n$: the number of heaps.
The next line has $n$ integers $x_1,x_2,\ldots,x_n$: the number of sticks in each heap.

第一行输入包含一个整数 $t$：测试用例的数量。之后描述 $t$ 个测试用例：
每个用例的第一行包含一个整数 $n$：堆的数量。
下一行包含 $n$ 个整数 $x_1,x_2,\ldots,x_n$：表示每一堆中的棍子数量。

## Output
For each test case, print "first" if the first player wins the game and "second" if the second player wins the game.

对于每个测试用例，如果先手玩家赢得游戏则输出 "first" ，如果后手玩家赢得游戏则输出 "second" 。

## Constraints
$1 \le t \le 2 \cdot 10^5$
$1 \le n \le 2 \cdot 10^5$
$1 \le x_i \le 10^9$
the sum of all $n$ is at most $2 \cdot 10^5$

## Example
**Input:**
```
3
4
5 7 2 5
2
4 1
3
4 4 4
```

**Output:**
```
first
first
second
```

这题完美地把前两题结合在了一起！它引入了博弈论中一个极其强大的思想——**等效替代（SG定理）**。

### 一、 降维打击：单堆石子的“真实威力”

既然我们不能随便拿了（最多只能拿 3 个），那我们先不看 N 堆，**单独只看 1 堆石子**，研究一下怎么赢。

假设只有 1 堆石子，每次可以拿 1、2、3 个。
我们在前面的讨论中提过，防守的最佳策略是当**“学人精”**。
你想想，什么数字能让你完美地当“学人精”？
**答案是：4。**

*   如果桌上只剩 **4** 个石子，轮到对手拿。
*   对手拿 1 个（剩3），你就拿 3 个（变0）。
*   对手拿 2 个（剩2），你就拿 2 个（变0）。
*   对手拿 3 个（剩1），你就拿 1 个（变0）。

只要桌上剩下 4 的倍数，无论对手怎么挣扎，你都能保证每一轮两人拿的**总和刚好是 4**。你就能把对手死死拿捏，直到拿到最后 1 个。

**这就得出了一个极其重要的结论：**
在“最多拿 3 个”的规则下，一堆数量为 $X$ 的石子，其实里面包含了若干个毫无意义的“4”。这些“4”双方谁也抢不到便宜，最后全都会被互相抵消掉。
因此，这堆石子真正的“战斗力”，只取决于它除以 4 的余数：$X \pmod 4$。

*   一堆 5 个石子 $\pmod 4 = 1$，它在游戏里的作用，**等价于** 1 个石子。
*   一堆 7 个石子 $\pmod 4 = 3$，它在游戏里的作用，**等价于** 3 个石子。
*   一堆 4 个石子 $\pmod 4 = 0$，它在游戏里的作用，**等价于** 没有石子（空堆）。

---

### 二、 魔法融合：把复杂游戏变成《Nim Game I》

博弈论中最伟大的定理之一 —— **SG 定理（Sprague-Grundy Theorem）** 告诉我们：
**任何规则的独立堆博弈，都可以等价替换成标准 Nim 游戏！**

在这个游戏里，由于每堆石子的规则都是“最多拿 3 个”，所以我们只需要把每一堆石子的数量 $X_i$，统统替换成 $X_i \pmod 4$。

替换完之后，这题就**完完全全变成了上一题的《Nim Game I》**！我们依然只看**异或和**！

**终极结论：**
计算 $S = (x_1 \pmod 4) \oplus (x_2 \pmod 4) \oplus \dots \oplus (x_n \pmod 4)$。
*   如果 $S \neq 0$，先手必胜（输出 `"first"`）。
*   如果 $S = 0$，后手必胜（输出 `"second"`）。

---

### 三、 样例推导验证

我们用题目给的样例来验证这个神仙结论：

**Test 1**: `4` 堆石子: `5 7 2 5`
*   先全部对 4 取模：
    *   $5 \pmod 4 = 1$
    *   $7 \pmod 4 = 3$
    *   $2 \pmod 4 = 2$
    *   $5 \pmod 4 = 1$
*   现在的等效局面变成了：`1 3 2 1`
*   算异或和：$1 \oplus 3 \oplus 2 \oplus 1 = 1 \neq 0$
*   **结果**：不为 0，先手必胜 (`first`)。与样例完全一致！

**Test 2**: `2` 堆石子: `4 1`
*   取模：$4 \pmod 4 = 0$，$1 \pmod 4 = 1$
*   等效局面：`0 1`
*   异或和：$0 \oplus 1 = 1 \neq 0$
*   **结果**：先手必胜 (`first`)。

**Test 3**: `3` 堆石子: `4 4 4`
*   取模：全都是 $0$
*   等效局面：`0 0 0`
*   异或和：$0 \oplus 0 \oplus 0 = 0$
*   **结果**：后手必胜 (`second`)。

### 四、 C++ 代码实现

代码和上一题几乎一模一样，唯一需要改动的地方，就是在读入石子数量 `x` 进行异或的时候，加上 `% 4`。

```cpp
#include <iostream>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    int xor_sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        // 唯一的改动：把原来的 x 改成了 x % 4
        xor_sum ^= (x % 4); 
    }
    
    // 异或和不为0先手胜，为0后手胜
    if (xor_sum != 0) {
        cout << "first\n";
    } else {
        cout << "second\n";
    }
}

int main() {
    // 性能优化：关闭同步，加快 cin/cout 速度
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

### 第一部分：为什么是 `% 4`？（余数的真实物理意义）

在上一题中，规则是“每次只能拿 1、2、3 个”。我让你把所有的石头数都 `% 4`（对 4 取余），你可能觉得这只是一个数学把戏。

现在我们从**真实对抗**的角度来看看，这个 `4` 到底是什么怪物。

#### 1. “黑洞”与“学人精”策略
假设桌子上有一堆恰好是 **4 个**的石子。
你先拿，你只能拿 1、2 或 3 个。
*   你拿 1 个，剩 3 个。对手拿 3 个，拿光了。
*   你拿 2 个，剩 2 个。对手拿 2 个，拿光了。
*   你拿 3 个，剩 1 个。对手拿 1 个，拿光了。

发现了吗？**只要一堆石子的数量是 4，先动这堆的人必死。** 对手只要采用“凑 4 策略”（你拿 $x$，他拿 $4-x$），这 4 个石子就一定会被对手拿完。

在博弈论里，这个 `4` 就像是一个**“黑洞”**，或者叫**“无效体积”**。它对先手没有任何帮助，纯纯的累赘。

#### 2. 余数就是“真实战斗力”
既然 4 个石子是无效的“黑洞”，那么如果一堆石子有 **13 个**呢？
我们可以把 13 拆成：$13 = 4 + 4 + 4 + 1$。
前面那 3 个 `4`，双方在博弈时都会心照不宣地互相“抵消”掉（你动一个4里的，我就在同一个4里补刀）。
所以，这堆多达 13 个的石子，在真正的高手眼里，**它就等价于只有 1 个石子！**

这就是 `% 4` 的物理意义：**剥离掉所有会被双方完美抵消的“无效黑洞”，剩下的余数，才是一堆石子真正在战局中发挥作用的“真实战斗力”。**

**👉 举一反三：**
*   如果规则是：每次最多拿 $m$ 个石子。
*   “黑洞”的大小就是 $m+1$。
*   等效操作就是：把每堆石子都对 $(m+1)$ 取余！

### 第二部分：规则不规律怎么办？（引入 SG 函数）

上面讲的 `% 4` 是非常幸运的情况，因为规则 `1, 2, 3` 是连续的，能凑出一个完美的黑洞 `4`。

但如果规则变得极其恶心，比如回到我们的第一题《Stick Game》：**每次只能拿 1, 3, 4 个石子。**
这个时候凑不出固定大小的黑洞了，怎么办？

这就需要请出博弈论的最终兵器：**SG 函数（Sprague-Grundy Function）**。

#### 1. SG 函数的核心思想：“战斗力评估器”
不管单堆的规则多离谱，SG 函数的作用就是给这个状态**打分**。
*   如果 $SG(x) = 2$，说明面对 $x$ 个石子时的局面，**完完全全等价于** 面对普通 Nim 游戏里的 2 个石子！
*   如果 $SG(x) = 0$，说明这个状态是必败态（等价于 0 个石子）。

#### 2. 怎么计算 SG 函数？（求 `mex` 的魔法）
计算 SG 函数只有一个极其简单的操作，叫做 **`mex`（Minimum Excluded，最小未出现非负整数）**。

*   **`mex` 的定义**：给你一个集合，找出里面**没有出现过**的**最小非负整数**（0, 1, 2, 3...）。
    *   `mex({1, 2, 3}) = 0` （因为 0 没出现）
    *   `mex({0, 1, 3}) = 2` （因为 0, 1 出现了，2 没出现）
    *   `mex({0}) = 1`

*   **SG 的计算规则**：当前状态的 SG 值 = **它能走到的所有下一步状态的 SG 值的 `mex`**。

#### 3. 实战推导：规则为只能拿 `1, 3, 4`
我们来看看怎么一步步给石子数量打分（评估战斗力）。

*   **0 个石子**：没法拿了。下一步状态的集合是空的 `{}`。
    *   $SG(0) = mex(\{\}) = 0$。（显然必败）

*   **1 个石子**：只能拿 1 个，变成 0 个石子。下一步的 SG 是 $SG(0) = 0$。
    *   $SG(1) = mex(\{0\}) = 1$。

*   **2 个石子**：只能拿 1 个，变成 1 个石子。下一步的 SG 是 $SG(1) = 1$。
    *   $SG(2) = mex(\{1\}) = 0$。（发现没？有2个石子时，你必败！）

*   **3 个石子**：能拿 1 个（剩2），或拿 3 个（剩0）。
    *   下一步的 SG 集合是 $\{SG(2), SG(0)\} = \{0, 0\}$。
    *   $SG(3) = mex(\{0, 0\}) = 1$。

*   **4 个石子**：能拿 1 个（剩3），3 个（剩1），4 个（剩0）。
    *   下一步的 SG 集合是 $\{SG(3), SG(1), SG(0)\} = \{1, 1, 0\}$。去重后是 $\{0, 1\}$。
    *   $SG(4) = mex(\{0, 1\}) = 2$。

**奇迹出现了！**
当我们算出 $SG(4) = 2$ 时，意味着什么？
意味着在“只能拿 1, 3, 4”的奇葩规则下，面对 **4 个石子**，它的**真实战斗力**等同于普通 Nim 游戏里的 **2 个石子**！

### 第三部分：举一反三的“万能公式”（以后遇到怎么做）

有了上面的基础，以后无论你在比赛里遇到什么样花里胡哨的博弈题（只要是两人轮流、信息公开、没法操作就算输），你都可以用这个**“万能三步曲”**来秒杀：

#### 终极解题工作流：

**第一步：无视有多堆，先盯住“一堆”求 SG 值。**
*   写一个动态规划（DP）或者递归数组，利用题目给的拿取规则。
*   从小到大算出 $SG(0), SG(1), SG(2) \dots SG(x)$。
*   状态转移方程永远是：`SG[i] = mex( 能走到的所有合法下一步的 SG 值集合 )`。

**第二步：打表找规律（如果数据量极大）。**
*   如果单堆的石子数高达 $10^9$，你不可能用数组去算 SG。
*   这个时候，你写个程序算出前 50 个 SG 值，**把结果打印出来！**
*   你一定会发现规律（比如循环节是 0, 1, 0, 1...，或者像刚才的取余 `x % 4`）。找出规律后，就能用 $O(1)$ 时间求出任意 $x$ 的 SG 值。

**第三步：多堆合体，异或秒杀！**
*   把 N 堆石子的真实数量 $x_1, x_2 \dots x_n$。
*   通过规律或者 DP 数组，转换为它们的战斗力评分：$SG(x_1), SG(x_2) \dots SG(x_n)$。
*   将这些 SG 值**全部异或起来**！
*   结果 $\neq 0$ 先手赢，结果 $= 0$ 后手赢。

### 总结
*   **对于简单的规则（比如拿1~m个）**：打表后你会发现 SG 值的规律刚好就是 `x % (m+1)`。这里的余数就是剥离了无效操作后的真实战斗力。
*   **对于复杂的规则**：老老实实用 `mex` 算出 SG 值。SG 值就是数学家发明的一个“翻译器”，它能把全世界任何乱七八糟的拿石头规则，**精准翻译**成大家最熟悉的普通 Nim 石子数。

这就是组合博弈论的尽头——**SG定理（Sprague-Grundy Theorem）**。你现在已经完全掌握它的精髓了！

### 第一步：什么是 SG 值？（它就是“威胁等级”）

在普通的 Nim 游戏（可以随便拿石子）里，一堆有 3 个石子的堆，它能变成 0个、1个、或 2个石子。
它为什么有威力？**因为它手里捏着变成 0、1、2 的权利。**

现在规则变了，变得奇形怪状（比如只能拿 1个 或 4个）。
有些石子堆虽然看起来很大，但它受到规则限制，**威力其实很弱**。

**SG 值的本质，就是无视表面上的石子数量，重新给这堆石子评定一个“真实的威胁等级”。**

*   **威胁等级 0**：废物状态。轮到你面对等级 0，你必输。
*   **威胁等级 1**：能一刀把局面变成“等级 0”丢给对手。
*   **威胁等级 2**：能随意把局面变成“等级 0”或者“等级 1”丢给对手。
*   **威胁等级 3**：能随意变成“等级 0”、“等级 1”或“等级 2”。

发现规律了吗？
**你想获得等级 $K$，你必须具备“变成比你低的所有等级（$0$ 到 $K-1$）”的能力！**

---

### 第二步：什么是 `mex`？（评级规则）

数学家发明的 `mex`，其实就是一个**极其苛刻的评级官**。

假设你是一堆受限的石子，你把你能变成的所有“下一步状态”的等级摆在评级官面前，评级官怎么给你定级？

*   **情况 A**：你只能变成【等级 0】和【等级 1】。
    评级官说：“你掌握了 0 和 1，那我就给你 **等级 2**。”
    *(这就是 `mex({0, 1}) = 2`)*

*   **情况 B**：你只能变成【等级 0】和【等级 2】。
    评级官大怒：“你想拿等级 3？你连【等级 1】都变不出来！基础都没打好，你缺什么，你的等级就是什么！你缺 1，你就是 **等级 1**！”
    *(这就是 `mex({0, 2}) = 1`)*

*   **情况 C**：你只能变成【等级 1】和【等级 2】。
    评级官冷笑：“你连把局面变成【等级 0】直接绝杀对手的能力都没有？你是个彻底的废物！你就是 **等级 0**！”
    *(这就是 `mex({1, 2}) = 0`)*

**总结 `mex` 的大白话规则：看你拥有的等级里，从 0 开始往上数，断层缺少的那个最小的数字，就是你的真实等级！**

### 第三步：实战演练（彻底看透 SG 的计算）

我们来玩一个奇葩规则：**每次只能拿 1 个 或者 4 个石子**。
我们从 0 个石子开始，一步步向评级官申请等级（算 SG 值）。

**0 个石子：**
我哪也去不了，没法变。
评级官：你啥也没有，缺少 0，你就是 **等级 0**。
👉 `SG(0) = 0`

**1 个石子：**
我拿 1 个，变成“0个石子”（等级 0）。
我拥有的下一步：【等级 0】。
评级官：你有 0，但缺 1，你是 **等级 1**。
👉 `SG(1) = 1`

**2 个石子：**
我只能拿 1 个（拿不了 4 个），变成“1个石子”（等级 1）。
我拥有的下一步：【等级 1】。
评级官：你只有 1，连 0 都没有！你是 **等级 0**！
👉 `SG(2) = 0`  *(极其反直觉：2个石子居然是个必败态！)*

**3 个石子：**
只能拿 1 个，变成“2个石子”（等级 0）。
我拥有的下一步：【等级 0】。
评级官：有 0，缺 1。你是 **等级 1**。
👉 `SG(3) = 1`

**4 个石子：**
拿 1 个 $\to$ 变成“3个石子”（等级 1）。
拿 4 个 $\to$ 变成“0个石子”（等级 0）。
我拥有的下一步：【等级 0】和【等级 1】。
评级官：0 和 1 你都有了，缺 2。你是 **等级 2**！
👉 `SG(4) = 2`

**5 个石子：**
拿 1 个 $\to$ 变成“4个石子”（等级 2）。
拿 4 个 $\to$ 变成“1个石子”（等级 1）。
我拥有的下一步：【等级 1】和【等级 2】。
评级官：你手里有 1 和 2，但是你变不出 0！基础不牢，你是 **等级 0**！
👉 `SG(5) = 0`

现在你看懂了吗？SG 的计算过程，就是从 0 开始，利用你**规则允许的动作**，去查找你下一步能到达的级别的集合，然后用 `mex`（评级官）找出那个从 0 开始第一个断层的数字。

---

### 第四步：算完 SG 有什么用？（异或大结局）

现在桌子上有 3 堆石子，数量分别是 **4个、2个、5个**。规则还是只能拿 1 或 4。

你要怎么判断输赢？
**第一步：不要看石子的表面数量，看它们的“威胁等级（SG值）”！**
*   4 个石子 $\to$ 查刚才的推导 $\to$ 威胁等级 `SG(4) = 2`
*   2 个石子 $\to$ 查刚才的推导 $\to$ 威胁等级 `SG(2) = 0`
*   5 个石子 $\to$ 查刚才的推导 $\to$ 威胁等级 `SG(5) = 0`

**第二步：把它们当成普通的 Nim 游戏，直接把等级异或起来！**
*   这局游戏等价于：普通 Nim 游戏里有 2、0、0 三堆石子。
*   计算异或和：$2 \oplus 0 \oplus 0 = 2$。

**第三步：看结果。**
*   结果是 2，不等于 0。
*   结论：**先手必胜！**

### 终极一句话总结

**SG 做法，就是利用 `mex` 这个评级官，把那些规则乱七八糟的石子堆，全部扒掉外衣，换算成它“相当于普通 Nim 游戏里的几个石子”，然后再用异或和（`^`）去秒杀！** 

这是博弈论最精妙的维度转换，看懂了这个，博弈论的门你就彻底跨进去了。
