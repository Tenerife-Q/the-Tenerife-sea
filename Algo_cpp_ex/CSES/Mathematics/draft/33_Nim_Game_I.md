# Nim Game I

## Problem Description
There are $n$ heaps of sticks and two players who move alternately. On each move, a player chooses a non-empty heap and removes any number of sticks. The player who removes the last stick wins the game.
Your task is to find out who wins if both players play optimally.

有 $n$ 堆棍子和两名轮流行动的玩家。在每一步行动中，玩家选择一个非空的堆并从中取走任意数量（至少一根）的棍子。取走最后一根棍子的玩家将赢得游戏。
你的任务是找出在双方都采用最优策略的情况下，谁会赢得游戏。

## Input
The first input line contains an integer $t$: the number of tests. After this, $t$ test cases are described:
The first line contains an integer $n$: the number of heaps.
The next line has $n$ integers $x_1,x_2,\ldots,x_n$: the number of sticks in each heap.

第一行输入包含一个整数 $t$：测试用例的数量。之后描述 $t$ 个测试用例：
每个用例的第一行包含一个整数 $n$：堆的数量。
下一行包含 $n$ 个整数 $x_1,x_2,\ldots,x_n$：表示每一堆中的棍子数量。

## Output
For each test case, print "first" if the first player wins the game and "second" if the second player wins the game.

对于每个测试用例，如果先手玩家赢得游戏则输出 "first" ，如果后手玩家赢得游戏则输出 "second" 。

## Constraints
$1 \le t \le 2 \cdot 10^5$
$1 \le n \le 2 \cdot 10^5$
$1 \le x_i \le 10^9$
the sum of all $n$ is at most $2 \cdot 10^5$

## Example
**Input:**
```
3
4
5 7 2 5
2
4 1
3
3 5 6
```

**Output:**
```
first
first
second
```

这题不需要任何复杂的动态规划，它存在一个**极其优美且反直觉的数学结论**。一旦掌握这个结论，这道题的代码只有短短几行。

下面为你详细解析这个被称为博弈论界“开天辟地”的定理。

---

### 一、 核心结论（Bouton 定理）

在标准的 Nim 游戏中，判断胜负的唯一依据是所有石子堆数量的 **按位异或和（Bitwise XOR Sum）**。

假设有 $n$ 堆石子，数量分别为 $x_1, x_2, \dots, x_n$。
设它们的异或和为 $S = x_1 \oplus x_2 \oplus \dots \oplus x_n$ （在 C++ 中使用 `^` 运算符）。

* **如果 $S \neq 0$**，那么先手必胜（输出 `"first"`）。
* **如果 $S = 0$**，那么后手必胜（输出 `"second"`）。

**就这么简单！** 无论石子堆数 $n$ 有多大，每堆石子 $x_i$ 有多大，只需将它们全部异或起来即可。

---

### 二、 为什么是“异或”？（底层逻辑推导）

在上一题《Stick Game》中我们总结过：
1. **必败态（L）**：无论怎么拿，都会把“必胜态”交给对手。
2. **必胜态（W）**：只要有一种拿法，能把“必败态”交给对手，就是必胜。

我们用“异或和 $S$”来验证这套逻辑：

**终点状态（游戏结束）**：
当所有石子都被拿光，即 $(0, 0, \dots, 0)$ 时，当前玩家无石子可拿，输掉游戏。
此时的异或和 $S = 0 \oplus 0 \dots \oplus 0 = 0$。这是一个显然的**必败态**。

**情况 1：如果当前 $S = 0$（证明这是必败态）**
假设你面对 $S=0$ 的局面。根据规则，你必须从某一堆 $x_i$ 中拿走若干石子，使其变成 $x_i'$ （且 $x_i' < x_i$）。
因为只改变了一个数字，新的异或和 $S' = S \oplus x_i \oplus x_i'$。
因为 $x_i \neq x_i'$，所以 $S'$ **必定不等于 0**！
**结论**：只要异或和为 0，无论你怎么拿，留给对手的异或和必然不为 0。

**情况 2：如果当前 $S \neq 0$（证明这是必胜态）**
假设你面对 $S \neq 0$ 的局面。你能不能找到一种拿法，让拿完后的异或和变成 0 呢？
**答案是：一定能！**
设 $S$ 的二进制表示中，最高位的 `1` 在第 $k$ 位。
那么在所有石子堆中，**必定存在至少一堆** $x_i$，它的第 $k$ 位也是 `1`（否则 $S$ 的第 $k$ 位不可能是 1）。
如果我们让这堆石子变成 $x_i' = x_i \oplus S$。因为 $x_i$ 和 $S$ 的最高位都是 1，异或之后这一位变成了 0，所以 $x_i' < x_i$（这是一个完全合法的操作，等于从 $x_i$ 中拿走了 $x_i - x_i'$ 个石子）。
拿完后，新的异或和变成了：$S \oplus x_i \oplus x_i' = S \oplus x_i \oplus (x_i \oplus S) = 0$！
**结论**：只要异或和不为 0，你**总能**找到一种方法，把异或和变成 0 扔给对手。

这就是为什么异或和完美契合了博弈论的状态转移！

### 三、 样例推导验证

让我们用题目给的 3 个测试用例来验证：

**Test 1**: `4` 堆石子: `5 7 2 5`
* $S = 5 \oplus 7 \oplus 2 \oplus 5$
* （异或有交换律和结合律，且 $A \oplus A = 0$）
* $S = (5 \oplus 5) \oplus 7 \oplus 2 = 0 \oplus 7 \oplus 2 = 5 \neq 0$
* **结果**：先手必胜 (`first`)

**Test 2**: `2` 堆石子: `4 1`
* $S = 4 \oplus 1 = 5 \neq 0$
* **结果**：先手必胜 (`first`)

**Test 3**: `3` 堆石子: `3 5 6`
* `3` 的二进制：`011`
* `5` 的二进制：`101`
* `6` 的二进制：`110`
* $S = 3 \oplus 5 \oplus 6 = 0$
* **结果**：后手必胜 (`second`)

输出完全吻合！

### 四、 C++ 代码实现

代码逻辑极度简单。由于 $x_i \le 10^9$，正好在 32 位有符号整数 `int` 的表示范围内，直接用 `int` 即可。

注意：本题测试用例较多（$\sum n \le 2 \cdot 10^5$），所以**快速 I/O 依然必不可少**。而且由于不需要保存前面的数据，我们甚至不需要开数组，一边读入一边异或即可，空间复杂度可以优化到 $O(1)$！

```cpp
#include <iostream>

using namespace std;

void solve() {
    int n;
    cin >> n;
    
    int xor_sum = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        xor_sum ^= x; // 不断将读入的堆大小进行异或
    }
    
    // 异或和不为0先手胜，为0后手胜
    if (xor_sum != 0) {
        cout << "first\n";
    } else {
        cout << "second\n";
    }
}

int main() {
    // 性能优化：关闭同步，加快cin和cout的速度
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

### 五、 复杂度与总结
* **时间复杂度**：$O(\sum n)$。只需要遍历一遍所有的输入数据即可，完全可以在 1.00s 的时限内通过 $2 \cdot 10^5$ 的数据量。
* **空间复杂度**：$O(1)$。没有使用任何数组，极度节省内存。

**总结**：这道题是组合博弈论的绝对核心。以后在算法竞赛中，只要遇到“两人轮流操作”、“状态有限”、“最后无法操作者输”的**公平组合游戏 (ICG)**，都可以通过 **SG 函数 (Sprague-Grundy)** 转化为 Nim 游戏，最终的求解都会落回这个神奇的**异或和**运算上。



没关系，博弈论的这个结论第一次接触时，100% 的人都会觉得“反直觉”和“像魔法一样”。我们抛开那些抽象的数学公式，**用最直白、最可视化的方式**重新盘一遍。

首先回答你的第一个问题：**是的，这里的“异或”就是二进制位上的按位异或（Bitwise XOR，C++中的 `^` 符号）。**

为什么要用二进制和异或？为了讲透这个，我们需要引入一个核心概念：**“天平的平衡”**。

---

### 第一步：理解“异或”到底在算什么？

在十进制里，你可能觉得 3、5、6 毫无规律。但如果我们把它们写成二进制，**对齐来看**：

```text
    3 的二进制：  0 1 1
    5 的二进制：  1 0 1
    6 的二进制：  1 1 0
-----------------------
按列统计 1 的个数: 2 2 2  (每一列都有偶数个 1)
```

**异或运算（`^`）的本质，就是“不进位的二进制加法”**。
它的规则很简单：**如果有偶数个 1，结果就是 0；如果有奇数个 1，结果就是 1。**

在上面的例子中，每一列 1 的个数都是 2（偶数），所以：
`3 ^ 5 ^ 6 = 000`（也就是 0）。

**核心比喻**：
*   当所有石子异或和为 `0` 时，意味着二进制的每一列上的 `1` 都恰好配对了（都是偶数个）。此时，我们称游戏处于**“完美平衡状态”**。
*   当异或和不为 `0` 时，意味着至少有一列的 `1` 是奇数个，没有配对。此时，游戏处于**“失衡状态”**。

---

### 第二步：为什么“平衡（异或为0）”必败，“失衡（异或不为0）”必胜？

我们要牢记游戏的终点：**所有石子被拿光，也就是 `0 0 0`**。
`0 0 0` 的异或和显然是 `0`。所以，**胜利者是那个把局面变成“平衡状态（0）”交给对手的人。**

现在我们来看看，为什么拿石子的规则完美契合了“破坏平衡”和“恢复平衡”。

#### 重新看 情况1：为什么面对“平衡（异或和为0）”，你必输？
假设桌子上的石子是 3、5、6。你算了一下，异或和是 0（完美平衡）。
轮到你拿石子了。规则规定，你**必须**从某一堆里拿走至少 1 个石子。

不管你怎么拿，你必然会改变某一堆石子的数量。
因为你**只改变了一堆**，所以它二进制的某几位一定会发生翻转（0变1，或者1变0）。
一旦某一位发生了翻转，这一列原本“偶数个 1”的完美状态，立刻就被打破了，变成了“奇数个 1”。

**结论：面对平衡状态（0），无论你怎么绞尽脑汁拿，只要拿了，就一定会把局面变成“失衡状态（非0）”。你只能眼睁睁地把不为0的残局交给对手。**

#### 重新看 情况2：为什么面对“失衡（异或和不为0）”，你必胜？
假设桌子上的石子是 2、4、5。我们排开看看：
```text
    2 的二进制：  0 1 0
    4 的二进制：  1 0 0
    5 的二进制：  1 0 1
-----------------------
按列统计1的个数: 2 1 1
异或和的结果是 :  0 1 1  (也就是 3)
```
现在的异或和是 `3`，不等于 `0`。游戏处于“失衡状态”。
因为它是失衡的，你一定能施展“魔法”，拿走一部分石子，让它**重新恢复平衡**（变成 0），然后把这个必败的平衡状态丢给对手。

怎么施展魔法呢？
1. 我们看异或和 `0 1 1`，最高位的 `1` 出现在中间那一列（也就是代表十进制 2 的那一列）。
2. 这说明，中间那一列现在有**奇数**个 1。
3. 往上看，是谁在中间那一列贡献了 `1`？是第一堆石子（2，也就是 `010`）。
4. 我们只要把第一堆石子从 `010` (2个) 变成 `001` (1个)，也就是从第一堆里拿走 1 个石子。

拿完之后，第一堆变成了 1。我们再来看看现在的局面（1、4、5）：
```text
    1 的二进制：  0 0 1
    4 的二进制：  1 0 0
    5 的二进制：  1 0 1
-----------------------
按列统计1的个数: 2 0 2
异或和的结果是 :  0 0 0  (变回 0 了！)
```
你看！你通过拿走 1 个石子，成功地把失衡（非0）变成了完美平衡（0）！
此时轮到对手了，对手面对 `0`，又回到了刚才的“情况1”，他被迫再次把局面弄乱，而你再次把它恢复平衡……直到最后你把 `0 0 0` 丢给他，你赢了！

---

### 终极总结（再念一遍这两句话）

1. **如果你拿到手时，异或和是 0**：所有的二进制位都是成对的。你动任何一堆，都会拆散某一对，导致异或和不再是 0。你被迫当苦力，必败。
2. **如果你拿到手时，异或和不是 0**：二进制位有落单的。你**总能**找到一堆合适的石子拿走几个，把那些落单的位重新凑成对，让异或和变成 0 丢给对手。你掌握了主动权，必胜。

这就是为什么只用算一下 `x1 ^ x2 ^ ... ^ xn` 是不是 0，就能判定生死了。

### 问题一：为什么“平衡状态（异或为0）”拿一次一定会失衡？能不能拿完之后还是平衡的（抵消掉）？

**答案是：绝对不可能抵消。**

为什么？因为游戏规则里有一条铁律：**你每次只能从「一堆」石子里拿。**

你想“抵消”，唯一的办法是你同时动**两堆**石子。比如第一堆少个 1，第二堆也少个 1，刚好扯平。
但规则不允许你动两堆！你只能动一堆。

我们回到二进制来看。假设你动了第一堆石子，把它从 5 变成了 3。
因为数字变了，它二进制里**至少有一位**发生了变化（要么 0 变 1，要么 1 变 0）。
既然只有这一堆的这一位变了，其他堆都没动，那这一列的 1 的总数，必然会从**偶数变成奇数**，或者从**奇数变成偶数**。
所以，原本配对完美（全为偶数，异或为0）的状态，只要你动了其中一个，必定被打破，绝不可能继续维持平衡。

### 问题二与问题三：这个游戏一开始就已经定胜负了吗？为什么把“平衡”丢给对手我就能赢？

**答案是：是的，对于两个绝顶聪明的人来说，这个游戏在开局看到石子数量的那一瞬间，胜负就已经决定了。** （这叫“完全信息博弈”，没有运气成分）。

为什么你一直把“平衡状态”丢给对手，最后赢的一定是你？
我们可以把整个游戏过程看作是一个**“下楼梯”**的过程：

1. **终点站**是全空 `(0, 0, 0)`。谁面对这个状态，谁就死。注意，`(0,0,0)` 是一个**完美的平衡状态**。
2. 假设一开始局面是**失衡**的。
3. **你的回合**：你是个高手，你施展魔法，拿走几颗石子，把局面变成**平衡**，丢给对手。
4. **对手的回合**：对手面对平衡状态，根据“问题一”的结论，他不管怎么挣扎（因为只能动一堆），拿完之后局面一定会变成**失衡**。
5. **你的回合**：你接手了一个失衡的局面，你再次施展魔法，把它变成**平衡**，丢给对手。

**发现这个死循环了吗？**
每当轮到对手时，局面永远是“平衡”的；每当轮到你时，局面永远是“失衡”的。
由于石子的总数在不断减少（大家都在拿），游戏总有一刻会走向终点。
既然**只有对手**才会面对“平衡状态”，那么最终面对 `(0,0,0)` 这个终极平衡状态的人，**必定是对手**。

你不需要管中间过程拿了多少次，你只要保证“你拿完总是平衡的”，你就把对手锁死在这条通往死亡的轨道上了。

### 问题四：如果不看二进制，在实际生活中该怎么拿？怎么体现这个“平衡”与“不平衡”？

这是个极其棒的问题。如果我们脱离枯燥的二进制，现实生活中的“平衡”长什么样？

为了让你秒懂，我们先不看 3 堆，我们看 **2 堆石子**。
假设有两堆石子：`5， 5`。
不看二进制，你凭直觉告诉我，这叫不叫“平衡”？
**这绝对是平衡，因为它长得完全对称！**

假设你面对 `5, 5` （对称/平衡状态），你怎么拿？
* 假设你从第一堆拿走 2 个，变成 `3, 5`。**（对称被打破，失衡了）**
* 对手怎么办？对手只需要**“学人精”**，你第一堆拿 2 个，他就在第二堆也拿 2 个。局面变成 `3, 3`。**（对称又恢复了，重新平衡）**
* 你再拿，比如把第一堆拿光，变成 `0, 3`。
* 对手再学你，把第二堆拿光，变成 `0, 0`。
* **你输了。**

看懂了吗？在 2 堆石子的游戏里，**“平衡”在现实中就体现为“两堆数量完全一样（对称）”。**
如果你面对一样的两堆，你必输，因为聪明的对手只要永远模仿你的动作，就能把你耗死。

**那如果扩展到 3 堆、4 堆甚至 N 堆呢？**

当石子变成 `3, 5, 6` 时，人眼已经看不出“对称”了。你不可能通过简单的“模仿”来维持平衡。
这也就是为什么这个问题在数学史上困扰了人们很久，直到 1901 年哈佛大学教授 Charles Bouton 发现了这个惊天秘密：
**N 堆石子之间，依然存在着一种极其隐蔽的“对称关系”，只不过这种对称不在十进制里，它隐藏在二进制的维度里！**
而这种隐藏的对称性，在数学上的表达公式，就是**“异或和等于 0”**。

### 最终总结

* **平衡状态（异或和为0）** = 局面处于一种“完美的对称”（虽然肉眼可能看不出来）。
* **失衡状态（异或和非0）** = 对称被打破了。
* **实际操作**：如果开局是对称的（异或为0），你就像那个面对 `5, 5` 的倒霉蛋，只要对手会玩“镜像模仿”，你必输无疑。如果开局是不对称的，你就可以主动去创造一个“对称”丢给对手，你必胜。

不用二进制的话，2 堆游戏靠人眼看对称就能赢；但面对 3 堆及以上的游戏，不借助二进制的异或，人类的大脑是无法直接看穿那种“高维度的对称”的。这就是算法和数学的魅力！
